## What is live

<Cards>
  <Card title="Teepin Inference" href="/docs/inference">
    Open models through one OpenAI-compatible API, paid per token. Confidential models run in hardware enclaves that prove what code they run.
  </Card>
  <Card title="Teepin Storage" href="/docs/storage">
    Buckets and files, encrypted on your device and sent straight to the storage network, with large files in parallel parts, uploads that resume after a crash, and share links.
  </Card>
  <Card title="SDKs" href="/docs/sdks/python">
    Python, Node and Go, with typed errors, safe retries and resumable uploads.
  </Card>
</Cards>

## The shape of it

- **One API.** Everything is at `https://api.teepin.com`. Requests carry an API key from your project.
- **Projects.** Buckets and keys belong to a project. Every account starts with a Default project.
- **Prepaid credit.** You top up first and usage draws it down. There are no bills after the fact.
- **No lock-in.** Inference is OpenAI-compatible, and every file you store can be downloaded in full at any time with the open-source SDKs, so your code and data can move.
